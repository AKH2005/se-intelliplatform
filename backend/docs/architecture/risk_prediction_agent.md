# Risk Prediction Agent Architecture Specification

## 1. Purpose
The `RiskPredictionAgent` is the first production-style supervised Machine Learning agent in SE IntelliPlatform. It provides automated, deterministic pre-project risk scoring for software projects based on verified historical risk metrics.

> **CRITICAL ARCHITECTURAL POLICY:**  
> The current Risk model is an experimental predictive model with weak measured performance and must not be interpreted as a highly accurate production risk predictor.

---

## 2. Input
The agent consumes the canonical `ProjectContextResponse` assembled by the Phase 2 `ProjectContextEngine`:
- **Context Source:** `context.project.settings` (under `ml_risk_inputs` or top-level settings).
- **Requirement:** All 5 pre-project predictors must be explicitly present and valid.
- **Zero Imputation Invariant:** Missing features raise `MLFeatureUnavailableError` immediately. Heuristic imputation or silent fallback is strictly prohibited.

---

## 3. Feature Schema
The agent uses the authoritative `1.0.0` feature schema defined in `app.ml.schemas.risk_features`:
- `project_size`: Enum (`Small`, `Medium`, `Large`)
- `team_experience_level`: Enum (`Low`, `Medium`, `High`)
- `estimated_effort_hours`: Positive float ($> 0.0$)
- `complexity_level`: Enum (`Low`, `Medium`, `High`)
- `requirement_stability`: Enum (`Unstable`, `Moderate`, `Stable`)

Outcome/leakage variables (`Actual_Effort_Hours`, `Budget_Deviation_Percentage`, `Schedule_Deviation_Percentage`, `Defects_Introduced`, `ML_Feasibility_Score`, `Project_ID`) are strictly excluded from input contracts.

---

## 4. Model
- **Algorithm:** Ridge Regression (`alpha=1.0`)
- **Version:** `1.0.0`
- **Feature Schema Version:** `1.0.0`
- **Artifact:** `backend/app/ml/artifacts/risk_model_v1.joblib`
- **Integrity Validation:** SHA-256 byte checksum recalculation against authoritative metadata (`backend/app/ml/artifacts/risk_model_v1_metadata.json`) on load.

---

## 5. Inference Flow
```text
ProjectContextResponse
        ↓
extract_risk_features()
        ↓
RiskFeatureVector (validated Pydantic model)
        ↓
RiskModelLoader (validates SHA-256 checksum & schema version)
        ↓
scikit-learn Pipeline (ColumnTransformer + Ridge)
        ↓
predicted_risk_score (continuous float on [1.0, 10.0])
        ↓
map_risk_score_to_level() (deterministic application policy)
        ↓
RiskPredictionCandidate (raw candidate)
        ↓
Deterministic Domain Validation
        ↓
RiskPredictionOutput
        ↓
AgentResult & AgentExecutionAudit
```

---

## 6. Risk Score
The model outputs a continuous regression target `predicted_risk_score` on an empirical ~1.0 to 10.0 scale:
- Not a probability.
- Never labeled as statistical confidence.
- Not generated by an LLM.

---

## 7. Risk Level Mapping
Risk bands are mapped strictly through deterministic application policy:

| Risk Level | Score Range | Operational Meaning |
| :--- | :--- | :--- |
| `LOW` | `score < 3.5` | Standard project governance and routine monitoring. |
| `MEDIUM` | `3.5 <= score < 6.5` | Heightened milestone reviews and effort tracking. |
| `HIGH` | `6.5 <= score < 8.5` | Mandatory architectural review and scope-freeze check. |
| `CRITICAL` | `score >= 8.5` | Critical project risk; escalated stakeholder review. |

---

## 8. Model Provenance
Every output includes complete model provenance metadata:
- `model_name`: `se_risk_regressor`
- `model_version`: `1.0.0`
- `algorithm`: `Ridge`
- `training_dataset`: `Reduced_Software_Project_Risk_Dataset_585.csv`
- `feature_schema_version`: `1.0.0`
- `artifact_checksum`: SHA-256 hash (`ca05173dcdd5f20d511079be41837abb1df9537e97efaa7e55fef54a53cd114c`)

---

## 9. Limitations
1. Dataset size is limited to 585 historical software development projects.
2. Training dataset is external to SE IntelliPlatform and may exhibit differing domain dynamics.
3. Current model exhibits weak predictive performance (Test $R^2 = -0.0087$, Test MAE = 2.1999 vs Dummy MAE = 2.2511).
4. Test $R^2$ is negative, indicating marginal improvement over a constant mean baseline.
5. Historical training performance does not guarantee real-world generalization on SE IntelliPlatform projects.
6. Runtime feature definitions must remain strictly compatible with the training dataset schema.

---

## 10. Failure Modes
- **Missing / Incomplete Features:** Raises `MLFeatureUnavailableError` (an `AgentValidationError`); `AgentExecutor` halts execution cleanly with `status=FAILED`, `error_code="VALIDATION_FAILED"`, 0 retries.
- **Corrupted Artifact / Mismatch:** Raises `ModelChecksumMismatchError`; execution fails deterministically.
- **Missing Artifact / Metadata:** Raises `ModelUnavailableError`.
- **Validation Rejection:** Numerical score outside $[1.0, 10.0]$, mismatched risk level, or empty limitations rejected by `validate_risk_prediction_output`.

---

## 11. Testing
- **Contract Tests:** `test_risk_prediction_contracts.py` (thresholds, score bounds, prohibited language checks).
- **Agent Lifecycle Tests:** `test_risk_prediction_agent.py` (lifecycle with actual trained model artifact, missing features).
- **Executor Integration Tests:** `test_risk_prediction_executor.py` (live vs snapshot context provenance, audit database persistence, immediate failure on invalid features).
