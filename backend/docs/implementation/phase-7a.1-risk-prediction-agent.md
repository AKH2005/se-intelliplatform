# Phase 7A.1 — Risk Prediction Agent

## 1. Objective
Implement and integrate the production-style `RiskPredictionAgent` into the SE IntelliPlatform agent infrastructure. The agent consumes canonical `ProjectContextResponse`, deterministically extracts pre-project risk predictors, executes local inference using the verified Phase 7A.0 Ridge regression pipeline, maps predictions into application-defined risk levels, and returns a validated `RiskPredictionOutput` via `AgentExecutor` with complete audit provenance.

---

## 2. Architecture
The Risk Prediction Agent follows the single execution authority architecture:
```text
ProjectContextResponse
        ↓
RiskPredictionAgent.analyze()
        ↓
extract_risk_features()
        ↓
RiskFeatureVector (validated Pydantic schema)
        ↓
RiskPredictionAgent.generate()
        ↓
RiskModelLoader (validates SHA-256 checksum & schema v1.0.0)
        ↓
Ridge regression pipeline (ColumnTransformer + Ridge)
        ↓
predicted_risk_score (continuous float on [1.0, 10.0])
        ↓
map_risk_score_to_level() (application policy thresholds)
        ↓
RiskPredictionCandidate
        ↓
validate_risk_prediction_output() (deterministic validation)
        ↓
RiskPredictionOutput
        ↓
AgentResult & AgentExecutionAudit
```

---

## 3. Input Contract
- **Input:** Canonical `ProjectContextResponse`.
- **Runtime Features:** Explicitly configured under `context.project.settings["ml_risk_inputs"]` (or top-level in settings):
  - `project_size`: "Small", "Medium", or "Large"
  - `team_experience_level`: "Low", "Medium", or "High"
  - `estimated_effort_hours`: Positive float
  - `complexity_level`: "Low", "Medium", or "High"
  - `requirement_stability`: "Unstable", "Moderate", or "Stable"
- **Strict Prohibition on Silent Imputation:** If any feature is missing, `MLFeatureUnavailableError` is raised immediately.

---

## 4. Feature Extraction
Feature extraction is delegated to `app.ml.features.risk_features.extract_risk_features()`, ensuring complete consistency between offline training and online inference. Features are validated into a `RiskFeatureVector` with `extra="forbid"`.

---

## 5. Model Integration
The agent loads the trained model through `RiskModelLoader` (`app.ml.inference.model_loader.get_risk_model_loader()`):
- Direct `joblib.load()` calls inside the agent are strictly forbidden.
- Artifact existence, SHA-256 byte checksum, and metadata schema version are checked before deserialization.
- Cached verified pipeline is reused across execution invocations without redundant reloads.

---

## 6. Risk Score
- **Scale:** Continuous float on approximately $1.0 - 10.0$ (derived from training dataset distribution).
- **Modality:** Supervised regression output (`predicted_risk_score`).
- **Policy:** Strictly not a probability; not labeled as statistical confidence; never generated by an LLM.

---

## 7. Risk Level Mapping
Risk level mapping is an explicit, transparent application policy:
- `LOW`: `predicted_risk_score < 3.5`
- `MEDIUM`: `3.5 <= predicted_risk_score < 6.5`
- `HIGH`: `6.5 <= predicted_risk_score < 8.5`
- `CRITICAL`: `predicted_risk_score >= 8.5`

The mapping is explicitly documented as application policy, not an ML classification output.

---

## 8. Output Contract
- **`RiskPredictionCandidate`**: Raw unvalidated output produced by local model inference.
- **`RiskPredictionOutput`**: Authoritative, validated final model:
  - `summary`: Descriptive assessment summary.
  - `predicted_risk_score`: Continuous float.
  - `risk_level`: Deterministic `RiskLevel` enum.
  - `feature_summary`: Dictionary of human-readable feature inputs.
  - `model_provenance`: `RiskModelProvenance` model.
  - `limitations`: List of acknowledged model limitations.

## 10. Limitations
The output contract requires inclusion of all 6 canonical limitations:
1. Dataset size is limited to 585 historical software development projects.
2. Training dataset is external to SE IntelliPlatform and may exhibit differing domain dynamics.
3. Current model exhibits weak predictive performance (Test $R^2 = -0.0087$, Test MAE = 2.1999 vs Dummy MAE = 2.2511).
4. Test $R^2$ is negative, indicating marginal improvement over a constant mean baseline.
5. Historical training performance does not guarantee real-world generalization on SE IntelliPlatform projects.
6. Runtime feature definitions must remain strictly compatible with the training dataset schema.

---

## 11. Validation
`validate_risk_prediction_output()` enforces:
1. `predicted_risk_score` is finite and in $[1.0, 10.0]$.
2. `risk_level` matches the application policy mapping for the score.
3. `feature_summary` contains all 5 required features.
4. `model_provenance` fields are non-empty and checksum is valid 64-character SHA-256.
5. `limitations` list is non-empty ($\ge 3$ statements).
6. Zero prohibited confidence/overstatement terms ("highly accurate", "high confidence", "% accurate", "% confident", "chance of being risky").

---

## 12. AgentExecutor Integration
- Executes via `AgentExecutor.execute(agent=risk_agent, context=context)`.
- Lifecycle hooks (`initialize`, `analyze`, `generate`, `validate_output`) execute in standard sequence.
- When features are missing, `MLFeatureUnavailableError` triggers immediate `AgentValidationError` handling: `status=FAILED`, `error_code="VALIDATION_FAILED"`, 0 retries.

---

## 13. Audit Integration
- Records `AgentExecutionAudit` with `agent_id="risk-prediction"`, `agent_version="1.0.0"`.
- Snapshot-backed context records actual `context_snapshot_id` and `context_version`.
- Live context execution explicitly records `NULL` for both snapshot fields (no fabricated provenance).
- `output_summary` records output payload keys.
