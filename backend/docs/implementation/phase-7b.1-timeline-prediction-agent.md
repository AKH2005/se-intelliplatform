# Phase 7B.1 — Timeline Prediction Agent Implementation Report

## 1. Objective
Implement and integrate the `TimelinePredictionAgent` into the SE IntelliPlatform agent infrastructure. The agent consumes canonical `ProjectContextResponse`, deterministically extracts function point planning features, executes local inference using the verified Phase 7B.0 Random Forest regression pipeline, and returns a validated `TimelinePredictionOutput` via `AgentExecutor` with complete audit provenance.

---

## 2. Architecture
The Timeline Prediction Agent follows the standard single execution authority architecture:
```text
                 ProjectContextResponse
                          │
                          ▼
                Timeline Feature Schema
                          │
                          ▼
                 Timeline Feature Extractor
                          │
                          ▼
                 Timeline Model Loader
                          │
                          ▼
                 RandomForestRegressor
                          │
                          ▼
             TimelinePredictionCandidate
                          │
                          ▼
               Deterministic Validation
                          │
                          ▼
                TimelinePredictionOutput
                          │
                          ▼
                    AgentExecutor
                          │
                          ▼
                  AgentResult + Audit
```

---

## 3. Input Contract
- **Input:** Canonical `ProjectContextResponse`.
- **Runtime Features:** Explicitly configured under `context.project.settings["ml_timeline_inputs"]` (or top-level in settings):
  - `afp`: Adjusted Function Points (float $> 0$)
  - `input_count`: Number of external inputs (float $\ge 0$)
  - `output_count`: Number of external outputs (float $\ge 0$)
  - `enquiry_count`: Number of external inquiries (float $\ge 0$)
  - `file_count`: Number of internal logical files (float $\ge 0$)
  - `interface_count`: Number of external interface files (float $\ge 0$)
  - `resource_level`: Staffing resource tier (1, 2, 3, or 4)
- **Zero Silent Imputation:** Missing features raise `TimelineFeatureUnavailableError` immediately.

---

## 4. Feature Extraction
Delegated to `app.ml.features.timeline_features.extract_timeline_features()`, validating input fields into a strict `TimelineFeatureVector` with `extra="forbid"`.

---

## 5. Model Integration
Loads the Phase 7B.0 trained artifact via `TimelineModelLoader` (`app.ml.inference.timeline_model_loader.get_timeline_model_loader()`):
- No direct `joblib.load()` calls inside the agent.
- Pre-execution SHA-256 byte checksum verification.
- Reuses in-memory cached model across invocations without retraining or reloads.

---

## 6. Prediction
- **Continuous Duration:** `predicted_duration_months: float` (full precision) and `estimated_duration_months: float` (rounded for presentation).
- **Target & Unit:** `Duration` in `months`.
- **Policy:** Strictly not a probability; not labeled as statistical confidence; zero LLM generation.

---

## 7. Output Contract
- **`TimelinePredictionCandidate`**: Raw candidate generated by model inference.
- **`TimelinePredictionOutput`**: Authoritative validated model:
  - `agent_id`: `timeline-prediction`
  - `agent_version`: `1.0.0`
  - `summary`: Descriptive assessment summary.
  - `predicted_duration_months`: Continuous float.
  - `estimated_duration_months`: Rounded presentation float.
  - `target`: `Duration`.
  - `target_unit`: `months`.
  - `model_provenance`: `TimelineModelProvenance`.
  - `feature_names`: Approved 7 features list.
  - `feature_summary`: Dictionary of human-readable inputs.
  - `limitations`: List of acknowledged model limitations.

---

---

## 9. Limitations
1. Scope is derived from 499 historical software development projects from the China metrics repository.
2. Predictions reflect empirical functional size associations; they do not imply direct causal levers.
3. Unmodelled human, organizational, and technical volatility accounts for remaining timeline variance.
4. Continuous regression point estimate in elapsed months; strictly not an infallible schedule guarantee or contractual deadline.

---

## 10. Validation
`validate_timeline_prediction_output()` enforces:
1. `predicted_duration_months` is finite float $> 0.0$.
2. `target == "Duration"` and `target_unit == "months"`.
3. `feature_names` exactly matches approved 7 predictors.
4. `feature_summary` contains all required features.
5. `model_provenance` fields are non-empty and checksum is valid 64-character SHA-256.
6. `limitations` list is non-empty ($\ge 3$ statements).
7. Zero prohibited confidence/overstatement terms ("guaranteed", "highly accurate", "high confidence", "% accurate", "% confident", "probability").

---

## 11. AgentExecutor Integration
- Executes via `AgentExecutor.execute(agent=timeline_agent, context=context)`.
- Standard lifecycle: `initialize` -> `analyze` -> `generate` -> `validate_output`.
- Missing features trigger immediate non-retried validation failure (`status=FAILED`, `error_code="VALIDATION_FAILED"`, 0 retries).

---

## 12. Audit Integration
- Records `AgentExecutionAudit` with `agent_id="timeline-prediction"`, `agent_version="1.0.0"`.
- Snapshot-backed context records actual `context_snapshot_id` and `context_version`.
- Live context execution records `NULL` for both snapshot fields.
- `output_summary` records execution payload keys.
